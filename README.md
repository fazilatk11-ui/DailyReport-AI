# DailyReport AI

An AI-powered WhatsApp assistant designed for schools and educational institutions to automate communication, answer FAQs, and manage conversation logs using AI automation workflows.

---

## Project Overview

DailyReport AI is a smart school assistant chatbot built using:

- n8n automation
- Twilio WhatsApp API
- OpenAI AI responses
- Google Sheets database

The system automatically:
- Receives WhatsApp messages
- Detects FAQ-based questions
- Sends instant automated replies
- Uses AI for unknown questions
- Stores conversations in Google Sheets
- Maintains structured AI chat logs

## Workflow Architecture

WhatsApp User  
↓  
Twilio Webhook  
↓  
n8n Workflow Automation  
↓  
Google Sheets FAQ Database  
↓  
Switch Logic  
↓  
AI Response / FAQ Response  
↓  
Google Sheets Chat Logs  
↓  
WhatsApp Reply
